# EventEase

## Project
Web-Based Event Registration and Management System

## Technologies
React
TypeScript
Vite
Tailwind CSS
Firebase Authentication
Cloud Firestore
Google Gemini AI

## Installation

1. Extract the project.
2. Open the project folder in VS Code.
3. Run:

npm install

4. Configure the required environment variables.
5. Run:

npm run dev

6. Open the local URL shown in the terminal.

## Note
The Gemini API key and other secret environment variables are intentionally
not included in this ZIP for security reasons.
